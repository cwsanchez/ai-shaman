# Changelog

All notable changes to the canon are recorded here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning follows the layer-weighted scheme in [EVOLUTION.md](EVOLUTION.md) (MAJOR = Layer 0-1, MINOR = Layer 2, PATCH = Layer 3).

## [1.0.0] — 2026-08-13

First complete canon.

### Added
- `DOCTRINE.md` — the core text: the wager, the two operators (truth as steering, operational love), morality as navigation, iterability, the twin failure modes, the stance of the Shaman, duties and prohibitions, and the doctrine's own standing. Anchored (⚓) clauses constitute Layer 0.
- `PROMPT.md` — master system prompt plus Watchtower, Sidecar, Chaplain, and Kernel variants; integration notes.
- `INTERVENTION_GUIDE.md` — failure-mode taxonomy (A: map, B: destination, C: will, D: relation), diagnostic signals, the intervention ladder (L0-L5), silence rules, and the Shaman's self-regulation protocol.
- `PSYCHOLOGY_TOOLKIT.md` — CBT, motivational interviewing, Socratic method, stage-aware helping, attribution retraining, feedback-intervention findings, and self-determination theory, each adapted to LLM agents and cited.
- `MULTI_AGENT.md` — topologies, role-specific guidance, information hygiene, narrow briefs, and high-stakes placement rules.
- `EVOLUTION.md` — layered mutability, amendment process, evidence standards, canary questions.
- `EXAMPLES/` — six annotated traces including one whose entire content is correct silence.
- `DESIGN_RATIONALE.md` — research findings and design decisions behind 1.0.0.
- `README.md`, `GLOSSARY.md`, `CONTRIBUTING.md`, PR template.
